Comment jouer sur le serveur ?

Rejoins le serveur, entre en file et affronte les meilleurs joueurs pour grimper dans le classement.

1

Connexion en 1.8.9

Lance ton jeu en version 1.8.9 (recommandé avec Badlion ou Lunar Client), ajoute l'adresse IP et connecte-toi.

2

Matchmaking rapide

Utilise le menu pour entrer en file d'attente Ranked Bedfight. Un adversaire de ton niveau te sera assigné.

3

Classement et gloire

Remporte tes duels pour gagner des points d'ELO, progresse de division et impose ton nom au sommet.

Tout ce que vous devez savoir

Les réponses aux questions les plus courantes concernant le serveur et le mode Ranked.

Le serveur est optimisé exclusivement pour la version 1.8.9, offrant le meilleur PvP. Nous conseillons Badlion Client ou Lunar Client.
